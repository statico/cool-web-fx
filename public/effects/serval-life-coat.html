Serval Life Coat

A halftone grid of tiny square dots with a serval's coat of spots hidden in it. The spots behind the active card light up purple and breathe, and a diagonal sparkle wave sweeps across the dots. Adapted for dark mode.

How it works

This ports the background behind "Full-stack ITSM built to replace ServiceNow" on serval.com. Serval calls it the LifeCoat. The site renders it with three.js WebGPU/TSL nodes. Here it is one plain WebGL2 fragment shader with the same math.

The coat (CPU). A grid of 7px cells is seeded with random rotated ellipses (servalSpotLevels: density 0.16, size 1.5). An 8-connected flood fill numbers the blobs, and each blob gets a centroid and radius. The class can run Conway's Life, but this section ships with paused: true, so the coat stays still.

The ink (CPU). A 96×96 ink field decays with τ = 0.7s. In card-center mode, the active card stamps a box of ink (0.5) the size of the card, with a smooth (1 − r)² falloff. Each blob takes the highest ink under its cells and eases toward it (in 0.12s, out 0.7s). A lit cell is boosted by 1 + glow · 7.2 · shape. The shape is set by the ink under the cell (glowRadial 0.65) and the distance from the blob's centre (glowCore 0.6). The 7.2 breathes ±20% at 2 rad/s.

The halftone (GPU). Square dots on a 5px grid. Each pixel samples the coat at its nearest grid point. Dot size is 0.37 + 0.1·luma (contrast 1.6). A diagonal sine wave (scale 6.5, speed 1.8, amount 0.27) shrinks the dots as it passes. Colour comes from a 4-stop ramp on luma.

Dark mode. On the live site the coat is hidden on the dark surface, so this is an adaptation. It uses Serval's own FEATURE_ROWS_DARK_SHADE palette (#302251 → #703fdc → #c3aeff) on #09070f, with grid dots at 9% #703fdc. The pointer wash is a screen-blended purple disc instead of the light theme's multiplied #ded3ff. Two intersected CSS gradient masks feather the edges, and the cards' 48px backdrop blur turns the lit dots behind them into a soft halo. Self-contained: no external scripts, fonts, or images.
